# Internationalization (i18n) & RTL

- Powered by `next-intl` (or `react-i18next` on the React side).
- Source of truth: `frontend/messages/<locale>.json`.
- Supported at launch: `en` (English, LTR), `fa` (Persian, RTL).
- Locale persisted in cookie + URL prefix.

## RTL behavior

- Tailwind: `dir="rtl"` on `<html>` triggers logical-property utilities (`ms-*`, `me-*`, `ps-*`, `pe-*`).
- Charts (TradingView Lightweight Charts) auto-flip.
- Numbers stay LTR inside RTL text using `<bdi>`.
- Currency: `﷼` is rendered identically in both directions.

## Adding a new locale

1. `frontend/messages/<locale>.json` — copy `en.json`, translate.
2. Register in `frontend/i18n/config.ts`.
3. Add a flag in the language picker.
4. Run `pnpm i18n:check` to ensure no missing keys.
