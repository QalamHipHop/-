## Deliberate Mainnet safeguards

The unsigned plan creates only a rent-exempt SPL mint and its owner associated-token account. It has initial supply zero, assigns mint authority to the owner public address, disables freeze authority, includes no platform transfer, and does not publish metadata or liquidity. The mint keypair is used only for the required partial signature and is never returned. Phantom must independently add the owner signature and broadcast after the user reviews the exact plan.

## Remaining hard stops

| Blocker | Why it prevents a public or Mainnet launch |
|---|---|
| No explicit owner approval in Phantom | A real signature and broadcast is an irreversible user action; it must remain outside this agent until the owner approves the exact transaction. |
| Metadata policy and immutable media URI absent | The repository does not supply a canonical image asset, hosting target, or definitive published token metadata. The transaction-builder intentionally omits metadata rather than fabricating it. |
| Issuance, backing, liquidity, and authority-governance policy absent | A zero-supply mint is technically safe, but issuing tokens or claiming RIAL backing requires approved economic, legal, and multisignature policy. |
| Production operator inputs absent | A real public deployment still requires domain, TLS certificate lifecycle, secret-manager values, authenticated Mainnet RPC endpoint, backups, alert receiver, and restore proof. |
| Current sandbox runtime uses development configuration | Production controls exist as a validated overlay; they are not activated with placeholder secrets. |

> No seed phrase, private key, wallet export, token supply, liquidity instruction, metadata mutation, or Mainnet broadcast has been requested, received, stored, or performed.

## Next controlled action

After the owner reviews the zero-supply specification and explicitly authorizes the action, they can use `/launchpad/mainnet-mint` in a Phantom-enabled browser. The page presents the owner, fresh mint address, zero supply, authority settings, instruction list, estimated rent/fee, and expiry height before calling Phantom. A successful signature must be followed by the read-only verifier and a recorded transaction signature before any launchpad record is linked to the Mainnet mint.
